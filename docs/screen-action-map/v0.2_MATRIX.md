| Column | Meaning |
|--------|---------|
| `id` | Stable row id |
| `type` | `entry_mode` \| `spatial_layer` \| `panel` \| `overlay` \| `modal` \| `dock` |
| `url_or_trigger` | URL query, CTA, voice tool, or gesture that opens it |
| `component_chain` | Mount path (e.g. `ExperienceCanvas → DualSphereCanvas → CosmographCanvas`) |
| `state_keys` | Store / React state that defines the surface |
| `mount_condition` | When it appears |
| `close_path` | How it dismisses |
| `expected_result` | Spec outcome |
| `actual_click_result` | Observed desktop click-through (fill in QA) |
| `mobile_result` | Observed phone/tablet (fill in QA) |
| `permission` | Audience / owner / public gate |
| `evidence` | Screenshot path, self-test id, or “unverified” |
| `commit` | SHA this row was validated against |
